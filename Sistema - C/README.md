TitanX Technologies - Simulador Orçamentário (Linguagem C)
Este é um projeto de extensão universitária desenvolvido por alunos da Universidade Nove de Julho (UNINOVE).

O projeto consiste em um software desenvolvido em Linguagem C e executado em modo console, responsável por realizar e simular orçamentos comerciais de maneira ágil, precisa e integrada para a empresa TitanX Technologies.

Funcionalidades do Sistema
O programa conta com um Menu Interativo com 5 opções principais de utilização:

Cadastro de Softwares: Permite adicionar licenças ao carrinho, diferenciando compras permanentes de modelos de assinatura mensal (SaaS) com base no período contratado.
Cadastro de Hardware: Menu para registrar componentes por código do produto, valor unitário e quantidade desejada.
Visualizar Carrinho: Exibe um relatório em formato de tabela com todos os itens já cadastrados, seus respectivos detalhes, preços unitários e quantidades.
Gerar Orçamento Final: Consolida o subtotal acumulado e aplica de forma automatizada um desconto de 10% para pedidos com valor superior a R$ 5.000,00.
Fechar o Programa: Encerra a execução do sistema com segurança.

Tecnologias e Conceitos Aplicados
Linguagem C (Padrão ANSI)
Estruturas de Dados: Matrizes/Vetores (Arrays) para armazenamento temporário de dados.
Estruturas de Repetição: Laços do...while para o fluxo do menu e validações, e for para varredura do carrinho.
Estruturas de Decisão: Blocos if...else e switch...case para controle de fluxo e regras de negócio.
Como Executar o Programa
Baixe o arquivo .c presente neste repositório.
Abra o arquivo em um compilador ou IDE de sua preferência.
Compile e execute o código fonte.
